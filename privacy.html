プライバシーポリシー

このページは、自分専用の「在庫管理ツール」（以下「本ツール」）が Google アカウントのデータをどう扱うかを説明するものです。本ツールの利用者は開発者本人だけです。

1. 利用するデータ

  • Gmail：メールの件名・差出人・本文、ラベル
  • Google カレンダー：本ツールが登録する予定

2. 利用の目的

  • 注文確認メールから、仕入れの記録の下書きを作るため
  • 受信トレイのメールを仕分けるため（メールマガジンのアーカイブとラベル付け、不要な通知の迷惑メールへの移動）
  • 抽選の受付・当選メールに書かれた日付を、カレンダーに予定として登録するため

メールの送信・削除は行いません。

3. 保存と第三者への提供

  • 読み取った内容は、開発者本人が管理するサーバーにだけ保存します。
  • データを販売したり、広告に使ったりすることはありません。
  • メールの内容を読み取るために、AI サービス（Anthropic 社の Claude API）に本文を送ることがあります。その際は、宛名・申込番号・口座情報などの行を取り除いてから送ります。
  • 上記のほかに、データを第三者に提供することはありません。

4. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と転送は、Google API Services User Data Policy（限定使用の要件を含む）に従います。

5. アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへのアクセスを取り消せます。
